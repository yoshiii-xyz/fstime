# Contributing

Keep changes within bounded, read-only filesystem traversal profiling in
`docs/product-brief.md`. Do not add a GUI, kernel tracer, cache flusher,
hosted service, or unrelated compatibility claim.

Run the commands in `docs/release.md` for release changes. Review the diff and
exact validation output before committing. Never put credentials, private
paths, or secret values in source, fixtures, logs, or QA evidence.
